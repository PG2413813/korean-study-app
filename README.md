# 韩语学习记录 App

一个**只在本地浏览器运行**的韩语单词记录与复习工具。双击一个 HTML 文件就能用，**不需要登录、不需要联网、不上传任何数据**。

> 产品需求与设计细节见 [PRD.md](./PRD.md)。

---

## 快速开始

直接双击打开根目录的 **`韩语学习记录.html`** 即可。

- 断网可用，数据保存在本机浏览器里，刷新 / 关闭 / 重启都不丢。
- 建议把它放到固定位置（如桌面）并加书签，后续一直用这一个文件。
- Chrome / Edge / Firefox 均可；手机上用浏览器打开同一文件也能用（自动切换为底部 Tab 布局）。

### 备份数据

进「数据与设置」→「导出备份文件」，会得到一个 JSON 文件。建议定期导出并存到网盘 / U 盘。
另外应用会**每天零点自动保存一份快照，保留 2 天**，误删可从设置页回滚。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 首页总览 | 今日待复习 / 今日新录入 / 错题总数三张卡，快捷录入，今日小卡 |
| 单词库 | 全部单词的检索、筛选、编辑、删除 |
| 每日学习录入 | 每天集中录入，自动记日期，次日进复习池 |
| 单词复习 | 中→韩 / 韩→中 × 打字 / 选择题 / 闪卡，共 4 种组合 |
| 错题库管理 | 连续答对进度，手动移除，只刷错题 |
| 时间管理 | 学习计时器、日 / 周 / 月趋势图、历史档案、成长总结 |
| 数据与设置 | 备份恢复、偏好设置、图片素材、自动保存、清空数据 |

**核心规则**：今天录入的词明天才进复习池；答错的词自动进错题库；错题连续答对 3 次（可改）自动移出。

## 开发

源码在 `app/`，构建产物是**单个 HTML**，会被复制到项目根目录覆盖 `韩语学习记录.html`。

```bash
cd app
npm install

npm run dev      # 开发服务器（热更新）
npm run build    # 构建单文件产物 → 根目录 韩语学习记录.html
npm run verify   # 跑全部测试（6 段，425 项断言）
```

### 各测试命令

| 命令 | 内容 |
| --- | --- |
| `npm run check` | 与 v1.0 备份的算法层逐函数对拍（153 项） |
| `npm run style` | 样式回归，逐条比对 v1.0 的取值（121 项） |
| `npm run smoke` | jsdom 跑构建产物：挂载、导航、各页面（39 项） |
| `npm run flow` | 端到端复习流程（27 项） |
| `npm run features` | 设置页、图片素材、自动快照等（50 项） |
| `npm run browser` | puppeteer 驱动真实 Chrome，验证样式与 IndexedDB（35 项） |

`npm run browser` 需要本机装有 Chrome 或 Edge；会在 `.shots/` 下留几张截图，可忽略。

## 两个构建上的坑（改代码前请先看）

1. **`postbuild.mjs` 不能省。** Vite 产出的是 ES module，而 module 脚本在 `file://` 下会被浏览器按 CORS 拦截 —— 直接双击会白屏。脚本做了两件事：把 `type="module"` 降级为经典 `<script>`，并把它从 `<head>` 移到 `</body>` 前（经典脚本立即执行，放 head 里时 `<body>` 还没解析，Vue 挂不上）。

2. **插入脚本必须用函数式替换。** `String.replace('</body>', 替换串)` 会把替换串里的 `$&` 当特殊记号展开，而压缩后的 Vue 代码里恰好含有 `$&`，会把脚本悄悄写坏。必须写成 `replace('</body>', () => ...)`。

## 隐私

- **所有数据只存在本机浏览器**，应用运行期间不产生任何对外网络请求。
- 仓库中**不包含** `backgrounds/` 下的任何图片（已在 `.gitignore` 中排除）。
- 上传的自定义图片也仅存本机，不会外传。
